# Figma navigation exports

These SVGs are exported from the [Men of Hunger UI Library](https://www.figma.com/design/YnuRSJB7p90n9jEY4mb4RN?node-id=52-44).
Edit the Figma masters first, then replace both state exports here and run `node scripts/build-icon-library.mjs` from the web repository.
The generator preserves vector geometry and converts the neutral Figma paint into each platform’s semantic tint. iOS uses one universal vector asset per state.

Icon foundations use Tabler (MIT); the selected Only me eye-slash is adapted from Heroicons (MIT). License texts are in the parent design directory.
