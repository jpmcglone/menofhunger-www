# Men of Hunger typography

Inter: interface, feed, chat, controls. Literata: scripture, articles, daily words and quotations.

Both apps ship these same OFL variable font sources (Google Fonts repository, retrieved 2026-09-09). Web WOFF2 files are losslessly compressed from the iOS TTF sources. Keep both apps and the Figma library in sync when updating fonts.

iOS custom text scales with Dynamic Type. Native system controls retain platform typography.
